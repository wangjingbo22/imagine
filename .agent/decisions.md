# 架构与过程决策记录

> 本文件用于记录必须人工确认的关键决策，避免后续“为什么这么做”无法追溯。

## 记录规则

- 每条决策都要写清背景、备选方案、最终结论、理由、影响范围
- 技术选型、核心接口调整、数据库设计调整、禁飞区划分等都应登记
- AI 可以帮助整理文字，但最终结论必须人工确认

## 决策模板

```md
## D-{编号} {决策标题}
- 日期：YYYY-MM-DD
- 背景：
- 备选方案：
  - 方案 A：
  - 方案 B：
- 最终选择：
- 选择理由：
- 影响范围：
- 风险与补救：
- 责任人：
```
