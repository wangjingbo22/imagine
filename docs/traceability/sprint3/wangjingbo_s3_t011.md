**Owner：** 王敬博

**完成日期：** 2026-09-01

## 交付内容

新增父行程预算账本页面：`/budget-ledger`。

- 按“第几天、交通/门票/餐饮/其他、费用项”展示预算明细；页面可为同城多日父行程提供逐日汇总基础。
- 每条费用都显示来源和事实状态：`实时来源`、`估算` 或 `待确认`。无金额的费用明确显示“待确认”，不会被计作 0 元或伪装为实时价格。
- 支持对既有条目录入人民币手动修正（包括负数修正），并立即重新计算“已计入预算”。
- 明确不包含支付能力；新增费用入口也不会创建支付或扣款动作。
- 页面在窄视口采用纵向汇总卡片，账本表格保留横向可读区域；所有新增可操作控件高度不小于 44px。
