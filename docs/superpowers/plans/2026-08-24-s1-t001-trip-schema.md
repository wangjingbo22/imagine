# S1-T001 Trip Schema Implementation Plan

> **For agentic workers:** Execute this plan task-by-task in the isolated `feature/czy-s1-t001-trip-schema` worktree. Git commits and pushes are handled by the designated Git-management task.

**Goal:** Build the Pydantic v2 `CityContext`/`Trip`/`Participant`/`TripDayInput` contract, field-level validation errors, JSON Schema snapshot, and Beijing/Shanghai/Chengdu fixtures for S1-T001.

**Architecture:** `backend/app/schemas/trip.py` is the single model source. `backend/app/schemas/validation_error.py` converts Pydantic structural errors and explicit single-day policy violations into a stable error envelope. `backend/tests/test_trip_schema.py` exercises the public `CreateSingleDayTrip` entry point; the generated JSON Schema snapshot is compared in tests.

**Tech Stack:** Python 3.11+, Pydantic v2, pytest, JSON fixtures. No API, database, Provider call, UI, or Plan implementation.

## Global Constraints

- Public S1 input is exactly one participant, one day, `mode=SINGLE`, `status=DRAFT`.
- `schemaVersion` is `Literal["1.0"]`; JSON Schema `$schema` metadata is separate.
- External JSON uses camelCase; Python attributes use snake_case aliases.
- Models use strict validation, `extra="forbid"`, and trimmed strings.
- Amounts are non-negative integer CNY cents; daily total must not exceed total budget.
- `cityCode` is a non-empty opaque string; no production Beijing default or city registry.
- `assistanceProfile` is omitted or `null` in S1; `PlanDay.tasks[]` is outside the input model.
- Do not add Sprint 2, P1, or Future fields.

```python
@pytest.mark.parametrize("fixture_name", ["beijing", "shanghai", "chengdu"])
def test_three_city_fixtures_validate_and_round_trip(fixture_name: str):
    raw = fixture_path(fixture_name).read_text(encoding="utf-8")
    trip = validate_trip_json(raw)
    recovered = validate_trip_json(trip.model_dump_json(by_alias=True))
    assert recovered == trip
    assert len(recovered.participants) == 1
    assert len(recovered.days) == 1


def test_missing_nested_field_reports_alias_path():
    payload = json.loads(fixture_path("beijing").read_text(encoding="utf-8"))
    del payload["days"][0]["timeWindow"]["end"]
    with pytest.raises(TripSchemaError) as exc_info:
        validate_trip_json(json.dumps(payload, ensure_ascii=False))
    assert exc_info.value.as_dict()["errors"][0]["path"] == "days[0].timeWindow.end"
    assert exc_info.value.as_dict()["errors"][0]["code"] == "missing"


def test_unknown_field_is_rejected():
    payload = json.loads(fixture_path("beijing").read_text(encoding="utf-8"))
    payload["cityContext"]["beijingFallback"] = True
    with pytest.raises(TripSchemaError) as exc_info:
        validate_trip_json(json.dumps(payload, ensure_ascii=False))
    assert exc_info.value.as_dict()["errors"][0]["code"] == "extra_forbidden"
```
